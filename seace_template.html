Regiones distintas
Estás abriendo el dashboard como archivo local. Para ver los requerimientos en pantalla sin descargarlos, ejecuta python seace_server.py y entra a http://localhost:8000. El botón “Ver PDF” solo funciona con el servidor local.
Requerimiento
Sobre el presupuesto: el SEACE no publica un presupuesto referencial para contrataciones menores (≤8 UIT) — el proveedor presenta su propia cotización antes del cierre. Por eso no aparece como columna aquí.
Sobre la coincidencia: el puntaje de prioridad se calcula por palabras clave de tu perfil (estructuras, expedientes técnicos, supervisión/consultoría de obra, BIM, instalaciones eléctricas/sanitarias, arquitectura) encontradas en la descripción del proceso. Revisa siempre el detalle en SEACE antes de decidir.
Fuente: API pública del Buscador de Contrataciones Menores del SEACE (prod6.seace.gob.pe), objetos “Consultoría de Obra” y “Servicio”, estado Vigente.
